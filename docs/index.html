Archipelago API (0.1.0)

Download OpenAPI specification:

Organization, people, payroll and contractor payments in one API.

Archipelago is an HR platform. Use the API to:

  • Manage your organization: businesses, teams and the individuals who work in them.
  • Pay your people: compensation, bonuses, expenses and reimbursements, paid straight to their bank accounts.
  • Let contractors get paid on demand: independent contractors charge their own customers by card or bank account.

Paying people

  1. Add a funding bank account to the business and a payout bank account to each individual.
  2. Give each individual a compensation. Archipelago creates a payable for every pay period.
  3. Approve bonuses and expenses. Approved bonuses and reimbursements become payables too.
  4. On the pay date, scheduled payables are paid out to each individual's bank account. Track them with the payable.paid and payable.failed webhooks.

Contractor payments

  1. Create an individual with employment_type: contractor and give them a bank account.
  2. Create their payment account. Once it's verified and enabled, they can accept payments.
  3. Create a checkout and share its checkout_url with the customer.
  4. When the customer pays, a payment is recorded and the funds settle to the contractor's bank account.

Authentication

Send an access token in the Authorization header of every request:

Authorization: Bearer <access_token>

Tokens are issued per API client through the OAuth 2.0 client-credentials flow and are scoped to your organization.

bearerAuth

Access token from the OAuth 2.0 client-credentials flow.

Security Scheme Type: HTTP
HTTP Authorization Scheme: bearer
Bearer format: JWT

Pagination

List endpoints are cursor-paginated. Pass limit (1-100, default 25), then pass page_info.end_cursor as after_cursor to get the next page, or page_info.start_cursor as before_cursor to get the previous one.

Amounts

Money is always an integer in the currency's minor unit, next to a lowercase ISO currency code: "amount": 150000, "currency": "usd" is $1,500.00.

Idempotency

Endpoints that create money movement (bonuses, reimbursements, checkouts and refunds) require an Idempotency-Key header. Retrying a request with the same key returns the original response instead of creating a duplicate. Keys expire after 24 hours.

Errors

Errors use standard HTTP status codes and the same body shape:

{
  "error": {
    "code": "validation_error",
    "message": "The request body is invalid.",
    "details": [{ "field": "email", "message": "is not a valid email address" }]
  }
}
Status Meaning
401 Missing or invalid access token.
404 The resource doesn't exist or isn't visible to your API client.
409 The action isn't allowed in the resource's current state, such as approving a bonus that was already paid.
422 The request body failed validation.

Webhooks

Archipelago sends events to the webhook URL configured for your API client. Each request has an Archipelago-Signature header in the form t=<unix timestamp>,v1=<signature>, where the signature is the hex HMAC-SHA256 of <timestamp>.<raw request body> keyed with your webhook secret. Respond with any 2xx status. Failed deliveries are retried with exponential backoff.
